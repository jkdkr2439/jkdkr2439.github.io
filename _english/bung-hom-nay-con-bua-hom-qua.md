You eat a clean bowl of rice and feel sick. You blame the rice.

Perhaps. But your stomach did not begin this meal empty. It still carries
yesterday's drink, this morning's medicine, old bacteria, little damage, and
the speed at which you ate.

New food enters an old stomach.

A new event enters an old mind in the same way. You do not store the past like
sealed meals in a freezer. When you remember, you build. A smell calls up one
piece. A present fear supplies another. A later story changes the shape. The
result may be honest and still not be a clean copy.

This is why two people can leave one room with different memories. It is also
why confidence is not a receipt. A memory can feel clear because the mind has
made a smooth story, not because every part survived.

None of this makes memory useless. If memory were worthless, you could not
find your own door. The past leaves marks. The point is that remembering is
work done now with material from then.

When a memory matters, do not ask only, “Do I feel sure?” Ask:

- What did I know at the time?
- What did I learn later?
- Which parts came from another person's telling?
- What record was made before the story had time to settle?
- What would I expect to be wrong if this memory was rebuilt?

Yesterday does not return untouched. It passes through today's stomach before
you speak it.
