# Blog identity principles

1. Canonical content and media are data; presentation work must not rewrite them.
2. Explicit manifests alone own book membership, order, and Canvas placement.
3. Every non-trivial module exposes a bounded recursive IPOD contract.
4. Gates report failures and never silently repair the source they judge.
5. Generated artifacts are outputs; they never become canonical source data.
6. When ownership is unclear, return here, then read the source map and the owning domain contract before editing.
7. Security, scalability, and debug visibility are invariants of every extension.
