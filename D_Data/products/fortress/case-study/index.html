FORTRESS Tower Defense

Game ? Canvas 2D

Overview

A complete tower defense game built with HTML5 Canvas 2D. Rich visual effects (gradients, glow, particles), 3 tower types, 4 enemy types, infinite wave escalation, and full economy system. Zero external assets ? everything rendered with Canvas primitives.

Design

Dark navy theme with warm gold accents. Textured grass (noise pattern), stone path (gradients), tower glow halos when firing, enemy HP bars, projectile trails, and particle death bursts. Glassmorphism UI panels. Responsive canvas that scales to viewport.

Architecture

packages/engine/  ? pure game logic (map, towers, enemies, combat, waves, economy)
apps/web/modules/ ? renderer (effects/glow), input (click-to-place), particles, game loop
apps/web/styles/  ? design system tokens + responsive layout

Engine modules have zero DOM dependencies. Renderer handles all Canvas 2D drawing with gradients, shadows, and compositing. Game loop uses requestAnimationFrame with dt-based timing for consistent 60fps.

Gameplay

  • 16?12 grid with snaking path
  • Arrow (50g, fast single), Frost (75g, slow effect), Cannon (120g, splash)
  • Runner, Tank, Swarm, Boss enemy types
  • Economy: earn gold from kills, wave bonus, spend on towers
  • Infinite waves with escalating difficulty

Play

Open FORTRESS ?

Click tower type ? click grass cell to place ? Start Wave. Survive as long as possible.
