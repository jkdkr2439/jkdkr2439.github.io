COMPOSE Workflow Builder

Productivity ? Automation

Overview

A local visual DAG workflow builder. Users compose multi-step automation workflows, execute them through a topological scheduler with retry, and inspect causal run history with per-step failure signatures.

Behavioral model

Primary actor: automation engineer composing and testing workflows locally. Trust: invalid graphs rejected before execution, failed steps preserve context, retry is bounded and observable.

Design decisions

Lenses: GOV.UK, WCAG, Tufte. Fractal 2-pass activated module_registry + fault_isolation mechanisms. Architecture: kernel validates manifests before mounting; fault boundary isolates failed module from canvas. First product with REAL UCG orientation (123k nodes ? 75 selected, 1200 token budget).

Architecture

apps/web/modules/      ? canvas, palette, connections, inspector, execution-view, history, main
packages/engine/       ? scheduler (Kahn topo sort), executor, validator (cycle detection), retry, fixture
packages/contracts/    ? workflow, node, connection, execution JSON schemas
infrastructure/        ? localStorage store + append-only event log
tests/                 ? engine/ contract/ integration/ static/ (87 tests)

Quality evidence

  • Pipeline: full UCG + behavioral + design + gates (10/10), fractal pass 2
  • Engine: topological sort, cycle rejection, retry limit 2, deterministic fixture
  • Fixture: 4-node workflow, action-1 fails attempt 1, passes attempt 2
  • Tests: 87/87 PASS + verifier 34/34 PASS
  • Browser: modules loaded via HTTP, click-to-place verified via CDP
