On design philosophy

Every design decision is a trade-off between competing values: density versus clarity, delight versus utility, personality versus universality.

A typeface is not neutral. A grid is not invisible. A color is not just a color. Each element carries history, convention, expectation — and each designer chooses which conventions to honor and which to subvert.

"The details are not the details. They make the design."

Charles Eames

What you see on this page is the same information, the same structure, the same semantic HTML — rendered through different eyes. The content does not change. The understanding might.
