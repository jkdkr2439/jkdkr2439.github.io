Overview

One specimen page, eleven design philosophies. Same HTML structure ? completely different visual experiences via CSS-only taste switching. Demonstrates how typography, spacing, layout, color, and component shape encode design identity.

Eleven tastes

  • Tufte ? Academic serif, data-dense, wide margins, evidence-first
  • Rams ? Monochrome minimal, borderless, silent confidence
  • Rand ? Bold primaries, geometric shapes, broken grid, symbolic wit
  • Vignelli ? Strict 12-col grid, Helvetica only, Swiss discipline
  • Lupton ? Experimental type, editorial magazine, layered
  • Kare ? Pixel aesthetic, monospace, window panels, 1984 Mac
  • IDEO ? Rounded, warm, organic spacing, workshop feel
  • Norman ? Heavy affordance, explicit feedback, appliance-like
  • GOV.UK ? Generous whitespace, large targets, trustworthy
  • Nielsen ? Maximum utility, dense info, function dominates
  • WCAG ? High contrast, 48px targets, accessible-first

How it works

A single semantic HTML specimen page with 6 sections (hero, stats, article, form, cards, navigation). The taste switcher swaps one CSS file ? no JavaScript re-rendering. Each taste overrides 40+ CSS custom properties plus layout classes, component shapes, and interaction states.

1 HTML ? 11 CSS = 11 completely different designs
Same content. Same structure. Different philosophy.

Architecture

  index.html           ? specimen (6 sections, static)
  styles/base.css      ? shared structure
  styles/tastes/*.css   ? 11 taste override files
  modules/switcher.js  ? toggle + URL sync
