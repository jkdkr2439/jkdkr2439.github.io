# Display domain IPOD

## Input

- Staged content registries, Canvas manifest data, route state, and user events.

## Process

- Compose layouts and includes.
- Render the Canvas, readers, navigation, and declared presentation state.
- Keep module DOM, CSS, and browser behavior inside their owning boundaries.

## Output

- Jekyll page sources, layouts, includes, CSS, JavaScript, and downloadable assets.

## Data feedback

- Browser state and validation evidence return through declared events and process reports.
- Display code never rewrites canonical authored content or manifests.
